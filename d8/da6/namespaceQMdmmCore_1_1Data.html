Judges winners of a Rock-Paper-Scissors output.

Parameters
judgersA kv-pair of the value a player outputs
Returns
A list of winners, with each value duplicates multiple times. The duplication times is equal to the number of players loses.

This is the core logic of which Rock-Paper-Scissors. Our rule is that winners can do actions on determined sequence by times that equals to the number of players loses.
