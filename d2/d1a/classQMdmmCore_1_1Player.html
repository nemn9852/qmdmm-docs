Detailed Description

The player playing MDMM Game.

This is the place where the data of each player is saved, and is the object where the data changed signal is emitted.

◆ setHp()

void QMdmmCore::Player::setHp ( int h,
bool * kills = nullptr )

setter of property hp

Parameters
hhp
kills(OUT) if this HP kills the player

This is not only a setter, but also the one triggers die() signal if this HP kills. A value of HP kills means before setting this HP the player is alive, and after setting this HP the player is dead.

A player is alive if hp is positive and dead if hp is negative. It depends on the configuration whether hp is 0 is treated as dead or alive.

See also
QMdmm::LogicConfiguration::zeroHpAsDead

◆ place

int QMdmmCore::Player::place
readwrite

the place of the player.

Note
The return value is not of type QMdmmData::Place . The reason is that the number of Cities should be same as the number of players in a room. Making a enumeration value of each City is not feasible. Since even the enumeration is created the value is still static_cast-ed and the enumeration will be of no use.
