Detailed Description

The network layer. It knows how players connect and exchange JSON packets, but delegates every rule decision to QMdmm Core library.

Server accepts connections and manages the rooms: each sign-in joins the recruiting room, and once that room is full it is handed to a LogicRunner, which carries one complete game – a QMdmmCore::Logic on a worker thread, plus one Agent and one ServerConnection per player. Client is the other end: it signs in, keeps a local mirror of the game state, and turns the traffic into request signals and reply slots. Socket is the single class behind all three transports (TCP, local socket and WebSocket).

Nothing here is tied to a user interface or to a particular executable – the CLI server, the GUI and the bots are all just Client / Server users.
